# RLCD 4.2 会議ミュート

- 通常起動後のBOOT短押し（離した時点）でマイク・スピーカーをまとめてOFF/ON。
- BOOTの3秒長押しは従来の診断表示。長押し後に離してもミュートは切り替わらない。
- OFF中は上部に `MIC + SPEAKER OFF` を表示し、PTTもハンズフリーも無効。
- 端末内の録音・再生を停止し、USB/Wi-Fiからの音声再生要求も拒否する。
- ミュート状態はNVSに保存する。通常の再起動やリンク切替で解除しない。
- 対応PCアプリはInputEvent 7（mute）/8（unmute）で進行中の会話をキャンセルし、mute時はRLCDのLive接続も終了する。解除でLiveを自動再開しない。
- PCのミュート操作UIは対象外。旧PCでも端末のミュートは有効だが、生成処理やLive通信を止めるには対応アプリが必要。
- BOOTを押したまま電源投入・リセットするとROMダウンロードモードになるため、ミュート操作は起動後に行う。

実機確認項目: 再生中/録音中/待機中の短押し、PTT無効、時計/キャラ/診断画面の表示、USB/Wi-Fi再接続、電源再投入、解除後の新規会話、古い返事が再開しないこと。
