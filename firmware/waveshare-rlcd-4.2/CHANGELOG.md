# RLCD 4.2 firmware changelog

## 0.2.0-preview

- Add onboard ES7210 microphone capture as 16 kHz PCM16 mono with half-duplex speaker arbitration.
- Add KEY push-to-talk and optional hands-free VAD, including local preroll, adaptive room-noise tracking, a bounded threshold, and live RMS/status reports.
- Add USB-only Wi-Fi provisioning, Protocol-v2 UDP discovery/TCP transport, USB fallback, and mutual HMAC-SHA256 device/host authentication.
- Route standard TTS, GPT-Live, and optional Beatrice audio generated by CharaDock on the PC; no local TTS model or dictionary is embedded.
- Prefer Wi-Fi while it is authenticated, recover the complete portrait/scene after reconnect, and retain USB as setup/fallback transport.
- Add sparse 1–2 px horizontal and diagonal idle portrait motion; capture, playback, and the ambient dashboard keep the portrait fixed.
- Let KEY open the clock dashboard from any idle character scene, enter it automatically after five idle minutes even from Conversation/Work, and redesign it with a large unscaled portrait crop on the right plus a white-paper hour/minute and environment panel on the left.

## 0.1.2-preview

- Add physically validated 16 kHz PCM16 mono playback through ES8311 and the onboard speaker amplifier.
- Start I2S MCLK before codec initialization, keep PA_EN low until verified mute/volume setup and a zero DMA prefill complete, and force PA_EN low after drain, stop, or failure.
- Buffer known TTS utterances completely in a 512 KiB PSRAM ring; use a 256 ms rolling prebuffer for longer streams.
- Enlarge USB CDC receive buffering so maximum-size 4096-byte Protocol-v2 audio frames remain intact during reflective-LCD refreshes.
- Route the selected CharaDock character TTS to RLCD 4.2 without extra PCM gain.

Microphone capture and Wi-Fi remained capability-gated in this preview.

## 0.1.1-preview

- Keep the last verified portrait visible until a complete replacement passes CRC and commits atomically.
- Add an eight-second USB heartbeat, a 24-second local Offline fallback, bounded host reconnect backoff, and complete Snapshot restoration after every handshake.
- Restore authoritative host scenes after temporary KEY overview, gated PTT feedback, interrupt, and BOOT diagnostics.
- Allow an immediate host sensor query so settings do not wait for the next 60-second report.
- Add a USB preflight tool covering device identity, capabilities, RTC sync, sensors, and heartbeat.
- Isolate the pioarduino/Arduino-ESP32 3.x package cache from ATOM and StackChan Arduino-ESP32 2.x builds.

Audio capture and Wi-Fi remained capability-gated in this preview.

## 0.1.0-preview

- Initial 400 × 300 ST7305 display, Shinonome Japanese text, Protocol v2 scenes, raw1-msb portraits, input, RTC, sensors, CharaDock desktop integration, and combined address-0x0 image.
